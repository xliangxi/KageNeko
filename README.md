> 当前版本：`1.0.0` · 支持平台：Windows 10/11 x64

KageNeko 是一款基于 Electron、Python 与 mitmproxy 构建的本地网络调试工具。它把实时流量、请求详情、断点拦截、证书管理和常用数据/媒体工具集中在一个桌面应用中，适合接口联调、客户端测试、网络问题定位与日常开发。

> [!IMPORTANT]
> KageNeko 仅用于你本人拥有或已获得明确授权的设备、应用与网络。请勿截取、修改或传播未经授权的通信数据。

## 主要功能

### 实时流量捕获

- 支持 `HTTP`、`HTTPS`、`TCP`、`WebSocket` 与 `UDP` 流量查看。
- 按协议、URL、状态码、Header 或内容快速筛选和搜索。
- 展示时间、进程、请求方法、状态码、主机、路径和数据大小。
- 状态栏实时统计各协议流量数量，并显示当前代理地址。

### 两种代理模式

| 模式 | 适合场景 | 说明 |
| --- | --- | --- |
| 驱动代理 | 只关注指定 Windows 应用 | 选择目标进程后捕获对应应用流量；需要管理员权限。 |
| IE 代理 | 浏览器、系统代理兼容应用及局域网设备 | 启动时配置 Windows 系统代理，默认监听 `0.0.0.0:2025`。 |

驱动代理会优先使用项目内置的本地重定向能力，并根据运行环境选择兼容链路。不同应用的网络栈、安全策略或证书固定机制可能影响捕获结果。

### 请求分析与调试

- 查看请求与响应的 Headers、Query、Body 和原始内容。
- 分别开启“拦截请求”和“拦截响应”。
- 使用 URL 关键词或通配符 `*` 缩小断点范围。
- 在断点中编辑 URL、Header、Query 或 Body 后继续发送。
- 重新发送历史请求，便于接口联调和结果对比。
- 收藏重要请求；收藏数据保存在本机。

### 网络条件模拟

- 设置下载速度、上传速度与网络延迟。
- 支持离线条件，用于检查超时、断网和弱网场景下的应用行为。

### 证书管理

- 检测 KageNeko MITM 根证书的本机信任状态。
- 一键安装到 Windows 受信任的根证书存储。
- 导出证书，供测试设备安装和信任。
- 一键复制当前代理地址。

## 开发工具箱

所有工具默认在本机处理数据，不主动上传输入内容。

| 分类 | 工具 | 能力 |
| --- | --- | --- |
| 数据 | URL 编解码 | 对 URL、参数或普通文本执行编码与解码。 |
| 数据 | Base64 编解码 | 支持 Unicode 文本。 |
| 数据 | JSON 工具 | 格式化、压缩、校验与树形查看。 |
| 数据 | JWT 解析 | 本地查看 Header 与 Payload；不代表签名已验证。 |
| 数据 | 时间戳转换 | 秒、毫秒时间戳与日期时间互转。 |
| 数据 | Markdown 预览 | 实时渲染 Markdown，支持拖入 Markdown 或文本文件。 |
| 图片 | 压缩 | 在浏览器可解码的格式范围内调整图片体积。 |
| 图片 | 尺寸调整 | 按目标尺寸生成新图片。 |
| 图片 | 格式转换 | PNG、JPEG、WebP 等常见格式互转。 |
| 视频 | 视频裁剪 | 选择时间区间并导出 MP4。 |
| 视频 | 封面提取 | 从视频帧导出 PNG、JPEG 或 WebP 图片。 |

视频裁剪依赖 FFmpeg。未安装时，KageNeko 会在首次使用相关功能时提示下载，也可以在“系统设置”中提前安装。

## 安装

### 直接安装

1. 下载 [KageNeko 1.0.0 Windows x64 安装包](release/KageNeko-Setup-1.0.0-x64.exe)。
2. 运行安装程序，按提示选择安装位置。
3. 启动 KageNeko；Windows 可能显示管理员权限确认，这是驱动代理、系统代理和证书管理所需。

安装程序会创建桌面和开始菜单快捷方式。若仓库托管到 GitHub，建议把约 121 MiB 的安装包发布到 GitHub Releases，而不是直接提交到普通 Git 历史。

### 运行要求

- Windows 10/11 x64。
- 管理员权限。
- 默认端口 `2025` 未被其他程序占用，或在启动前改用其他端口。
- 使用视频裁剪时需要 FFmpeg；首次下载需要联网。

## 快速开始

1. 打开“实时流量”，确认监听端口，默认值为 `2025`。
2. 选择“驱动代理”或“IE 代理”。使用驱动代理时，选择需要调试的目标进程。
3. 点击“启动代理服务”。
4. 在目标应用中发起网络请求，流量会出现在列表中。
5. 使用协议按钮或搜索框缩小结果，点击一条记录查看完整请求与响应。
6. 如需修改通信，设置 URL 拦截关键词并开启请求或响应拦截。
7. 完成调试后停止代理服务，避免系统流量继续经过调试代理。

### 模式选择建议

- 调试单个桌面应用：优先尝试“驱动代理”，并只选择目标进程。
- 调试浏览器或遵循 Windows 系统代理的应用：使用“IE 代理”。
- 调试手机或平板：使用“IE 代理”，让设备与电脑处于同一局域网，并按下一节配置代理与证书。

## HTTPS 证书与移动设备

HTTPS 内容只有在客户端信任 KageNeko 根证书、且目标应用未启用证书固定等额外校验时才能解密。

### Windows 本机

1. 进入“证书管理”。
2. 点击“安装到本机”。
3. 确认系统显示证书已受信任。
4. 重启需要调试的浏览器或应用后再次请求。

### 局域网移动设备

1. 保证电脑和移动设备位于同一可信局域网。
2. 启动 IE 代理，并确认防火墙允许所选端口的入站连接。
3. 将设备的 HTTP 代理设置为运行 KageNeko 的电脑 IP 和端口。
4. 从“证书管理”导出根证书，安装到测试设备并按系统要求启用信任。
5. 回到“实时流量”确认设备请求。

> [!WARNING]
> 根证书具有解密 HTTPS 流量的能力。只在受控测试设备上安装，妥善保管导出的证书，测试结束后可通过系统证书管理工具移除不再需要的信任项。



## 数据与隐私

- 抓包会话为临时数据，关闭应用后不作为云端历史保存。
- 收藏、设置和工具输入等本地状态保存在当前电脑上。
- 数据工具、图片工具和视频工具在本机处理。
- 敏感 Header 隐藏功能可遮盖 `Authorization` 与 `Cookie` 等内容；分享截图或日志前仍应自行复核。
- 使用上游代理或局域网代理时，数据还会经过你主动配置的网络节点；请确认其可信度。

## 常见问题

### 启动后没有任何流量

- 确认代理服务已成功启动，端口未被占用。
- 驱动代理下确认选中了正确进程；进程重启后可重新选择。
- IE 代理下确认目标应用遵循 Windows 系统代理。
- 检查 Windows 防火墙、安全软件或其他代理/VPN 是否阻止连接。
- 先关闭其他系统代理、抓包软件或占用相同端口的程序，再重试。

### HTTPS 只能看到连接，看不到明文内容

- 在“证书管理”中安装并信任 KageNeko 根证书。
- 重启目标应用后再测试。
- 部分应用使用证书固定或自定义网络栈，可能不会接受本地调试证书。请勿尝试绕过不属于你的应用或系统的安全保护。

### 驱动代理启动失败

- 使用管理员权限运行 KageNeko。
- 检查杀毒软件或 Windows 安全策略是否阻止驱动/网络重定向组件。
- 可临时改用 IE 代理，判断问题是否仅发生在驱动链路。

### 手机无法连接代理

- 确认手机与电脑处于同一局域网，且不是启用了设备隔离的访客网络。
- 代理主机应填写电脑的局域网 IP，而不是 `127.0.0.1`。
- 允许 Windows 防火墙访问 KageNeko 的监听端口。

### 视频裁剪不可用

- 在“系统设置”中检查 FFmpeg 状态并执行安装。
- 确认网络可以下载 FFmpeg 静态组件。
- 输入视频需要是当前 Chromium/FFmpeg 能够读取的格式和编码。

欢迎提交问题报告和改进建议。提交问题时建议附上：

- KageNeko 版本、Windows 版本和代理模式。
